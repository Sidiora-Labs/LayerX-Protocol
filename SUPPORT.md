# Support

This repository is a protocol reference implementation under active
qualification. It does not provide a hosted service, custody service, production
SLA, or permission to deploy the contracts with real assets.

Use GitHub issues for reproducible build failures, protocol conformance
questions, and non-sensitive defects. Include the operating system, compiler or
Foundry version, exact command, complete error output, and the smallest input
that reproduces the problem.

Use GitHub discussions, when enabled, for design questions that do not disclose
security-sensitive information. Report suspected vulnerabilities only through
the private process in [SECURITY.md](SECURITY.md).

Requests involving deployment, validators, custody, migrations, or real-value
canaries require explicit authorization and a separately reviewed runbook. They
are not implied by source access or by maintainer participation in an issue.
